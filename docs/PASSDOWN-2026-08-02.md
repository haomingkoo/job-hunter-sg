## Landed behavior

| Area | Current contract |
|---|---|
| Readiness and reads | AI readiness probes the configured model. Read-only recruitment endpoints do not construct live models or require a SEA-LION key. |
| Coordinator | A deep-agent tool loop sees the durable thread, current shortlist, candidate evidence, resume block IDs, and visible plan. Prose-only model replies complete without a hidden 503 fallback. |
| Preferences and queue | One invalid preference cannot discard the turn. Independent preferences retract independently. Messages queued during a run persist in order. |
| Resume study | A resume-version profile starts automatically, resumes from durable checkpoints, and is reused only for the same document revision. Logical blocks no longer split wrapped sentences. |
| Search and salary | Search exposes current posting facts, requirements, ATS terms, sector, seniority, and peer salary-floor context. Missing employer pay remains missing and is never replaced by a median. |
| Ranking | Published matches separate role level and pay position, cite verbatim resume evidence, preserve posting variants, and expose additions and withdrawals. |
| Editing | Evidence-supported edits are drafted without a second permission gate. Accepting one creates a new non-master resume version and keeps the active thread, plan, messages, and matches. |
| Resume document | PDF, DOCX, pasted text, preview, scoring, tailoring, and agent review share one layout-aware canonical document. Unknown headings remain explicit custom sections or visible confirmation candidates; the browser no longer re-parses raw text semantically. |
| Assessment | Specialists receive their declared limitations, score meaning, citation requirements, and untrusted-data rule. The independent judge receives candidate evidence and missing-specialist records. `revise` receives a bounded correction and fresh judgment. |
| Operations | Tool/run linkage, duration, model, and safe failure metadata persist. Idle JD summarization runs only through explicit administrator actions. API and MCP use the same module-relative SQLite path. LangGraph checkpoints allow only declared recruitment payload types beyond its safe built-ins. |

## Durable cautions

- A green unit suite is not proof of model stopping, tool selection, streaming, or
  rendered behavior. Repeat browser acceptance when those seams change.
- A failed search is unknown, never zero results. Missing salary is unknown, never the
  peer median.
- Tool refusals must include the actionable alternative or missing identifier; opaque
  refusals can cause repeated calls until the step cap.
- Model work stays outside the conversation lock. Durable event writes take the lock
  only to allocate ordered sequence numbers.
- Do not recreate parallel persona pipelines or hidden tool defaults. Extend the current
  candidate-profile, coordinator, and target-assessment seams.
- Remove tests with deleted behavior; retain evidence, safety, persistence, and visible
  contract coverage.
