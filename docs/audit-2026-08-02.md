## The pattern

Over-engineering here is not speculative architecture built up front, it is the residue of migrations that deleted the caller and kept the callee: a retired bounded runner whose config knobs, prompt constants and `correction` field are still stamped into every artifact, a `tooling/` package whose defaults no call site takes, and three modules forming a feature triangle nobody routes to. The second shape is a declared single source of truth that never finished absorbing its copies, so `shared/resume-classification.json`, `STORY_TAGS`, `ats_terms.py` and `apiFetch` each sit next to two or three hand-typed duplicates, and the duplicates have already drifted into live inconsistencies (`RPA` vs `Rpa`, four templates out of eight, `additional_information` vs `personal`). The third is defensive layering that the framework below already does: pydantic length checks re-implemented on top of `min_length`, `model_dump` recursion hand-rolled next to a sibling that calls it in one line, and a repeat guard inside a tool that middleware already blocked before the handler ran.
